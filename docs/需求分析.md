# 基于SpringBoot的培训学习交流系统 需求清单
## 一、整体业务需求
|需求类别|核心需求描述|
| ---- | ---- |
|行业痛点解决|解决线上培训领域资源分散、师生互动不足、学习进度无追踪、管理效率低下的问题|
|闭环服务构建|形成**学习、交流、管理**一体化的线上培训闭环服务体系|
|适配性要求|采用轻量化设计，适配国内中小培训机构的使用需求，支持多终端浏览器访问|
|核心目标|实现培训资源整合、学习互动强化、培训全流程数字化管理，提升学习体验与管理决策效率|

## 二、角色专属功能需求
### （一）学员角色
|需求模块|具体需求点|
| ---- | ---- |
|注册登录|1. 支持学员自主注册账号，系统校验账号唯一性、密码一致性<br>2. 账号密码登录系统，支持密码修改|
|课程学习|1. 按分类、关键词检索/浏览课程，查看课程详细信息（介绍、周期、报名条件等）<br>2. 提交课程报名申请，接收报名审核结果通知<br>3. 报名通过后在线观看课程视频，系统自动记录学习进度<br>4. 支持课程学习断点续学，实时查看个人学习进度|
|资料获取|1. 下载已报名课程的课件、学习资料等资源<br>2. 支持课程资源在线查看、收藏，方便随时查阅|
|作业管理|1. 在线查看教师发布的作业题目、提交截止时间<br>2. 在截止时间内在线提交作业，支持作业重新编辑与再次提交<br>3. 查看教师的作业批改结果、评分及评语|
|互动交流|1. 在学习交流论坛发布学习问题、分享学习心得<br>2. 回复论坛内其他学员/教师的帖子，参与话题讨论|
|个人中心|1. 修改个人基本信息（姓名、手机号、邮箱等）<br>2. 查询个人课程报名记录、作业完成情况、课程总成绩<br>3. 统一查看个人学习相关数据，实现自主学习管理|

### （二）教师角色
|需求模块|具体需求点|
| ---- | ---- |
|登录与个人管理|1. 账号密码登录系统，支持密码、个人信息修改<br>2. 查看个人发布的课程、作业及对应的学员数据|
|课程与资源管理|1. 发布课程信息（名称、介绍、培训周期、报名条件等）<br>2. 为已发布课程上传课件、视频、学习资料等课程资源<br>3. 支持课程信息、课程资源的修改与删除|
|报名审核|1. 查看学员的课程报名申请，进行审核操作（通过/驳回）<br>2. 审核结果同步至系统，由系统向学员发送通知|
|作业管理|1. 发布课程作业（名称、内容、提交截止时间等）<br>2. 支持作业题目的修改、删除，查看学员作业提交情况（已提交/未提交）<br>3. 在线批改学员提交的作业，给出评分与评语<br>4. 标记未提交作业的学员，支持系统内提醒功能|
|成绩管理|1. 录入学员的课程考试成绩<br>2. 结合作业成绩，系统自动/手动计算学员课程总成绩<br>3. 统计所授课程学员的成绩分布、平均分、及格率等数据<br>4. 生成成绩统计报表，支持报表导出|
|互动交流|1. 在学习交流论坛回复学员提出的问题<br>2. 发布学习相关话题，引导学员讨论<br>3. 对论坛内违规帖子进行管理（删除、屏蔽）|
|数据查看|1. 统计所授课程的报名量、实际学习量<br>2. 查看所授课程学员的整体学习情况，掌握学习进度整体分布|

### （三）管理员角色
|需求模块|具体需求点|
| ---- | ---- |
|登录与权限管理|1. 账号密码登录系统，区分普通管理员/超级管理员权限<br>2. 对学员、教师、管理员的角色权限进行精准管控，分配操作权限|
|用户信息管理|1. 对学员、教师信息进行增、删、改、查操作<br>2. 支持学员、教师信息的批量导入与导出<br>3. 管理用户账号状态（启用/禁用），处理账号异常问题|
|课程资源管理|1. 审核教师发布的课程信息，进行审核操作（通过/驳回）<br>2. 对课程进行分类整理，维护系统课程库<br>3. 支持课程的下架、修改操作，统计各课程报名量、学习量<br>4. 对系统内课程资源进行统一管理，清理无效资源|
|流程监督与管理|1. 监督课程报名审核、作业批改的整体流程，确保流程规范<br>2. 查看系统内所有作业的提交、批改情况，统计整体作业完成率、及格率<br>3. 对系统内所有学员的课程成绩进行统一管理，支持成绩修改与查询|
|数据统计与可视化|1. 统计系统运营核心数据：课程总报名量、论坛发帖量、用户活跃度等<br>2. 统计学员整体学习数据：作业完成率、平均分、各课程成绩分布等<br>3. 通过柱状图、折线图、饼图等形式实现数据可视化展示<br>4. 支持统计数据的筛选、查询，为管理决策提供数据支撑|
|系统维护|1. 保障系统稳定运行，进行日常运维操作<br>2. 对系统功能进行升级、优化，处理系统故障<br>3. 管理系统论坛，清理违规内容，维护交流环境|

## 三、技术与非功能需求
### （一）技术架构需求
|需求类别|具体需求点|
| ---- | ---- |
|整体架构|采用B/S架构，前后端分离开发模式|
|后端技术|以SpringBoot为核心框架，搭配MyBatis实现数据交互，集成Spring Security实现权限管控|
|前端技术|基于Vue.js+ElementUI构建可视化界面，支持组件化开发，实现路由管理与异步数据交互|
|数据存储|选用MySQL数据库存储业务数据，支持复杂多表查询与数据优化|
|数据可视化|集成ECharts图表库，实现各类统计数据的直观展示|
|接口设计|采用RESTful风格设计接口，支持跨域访问，确保前后端交互顺畅|
