# 培训学习交流系统 详细需求列表

## 1. 角色管理与登录系统
- [x] **学员功能**: 自主注册账号，账号密码登录，修改个人信息及密码。
- [x] **教师功能**: 账号密码登录，修改个人信息及密码。
- [x] **管理员功能**: 账号密码登录，分配超级管理员和普通管理员权限，管理学员和教师账号状态（启用/禁用）。
- [x] **权限管控**: 基于Spring Security实现细粒度的角色权限控制（RBAC）。

## 2. 课程资源模块
- [x] **教师发布课程**: 教师录入并发布课程信息（名称、周期、报名条件等）。
- [x] **管理员审核课程**: 管理员对教师发布的课程进行审核（通过/驳回），并可执行下架操作。
- [x] **教师上传资源**: 教师为已发布课程上传视频、课件等资源。
- [x] **学员检索与查看课程**: 学员按分类或关键字搜索课程，查看课程介绍及资源。

## 3. 报名审核模块
- [x] **学员报名**: 学员向已发布的课程提交报名申请。
- [x] **教师审核**: 教师对学员的报名申请进行审核（通过/驳回），系统通知结果。
- [x] **我的课程**: 学员查看已通过审核的课程记录并开始学习。

## 4. 作业与批改模块
- [x] **教师发布作业**: 教师针对特定课程发布作业及截止时间。
- [x] **学员提交作业**: 学员在线完成并提交作业，支持截止前重新提交。
- [x] **教师批改作业**: 教师查看提交情况，批改并给出评分及评语。
- [x] **管理员监督**: 管理员可查看全系统作业提交及批改统计。

## 5. 成绩与统计模块
- [x] **教师录入成绩**: 教师录入期末考试成绩，结合系统计算得出课程总分。
- [x] **学员查询成绩**: 学员在个人中心查看课程得分。
- [x] **管理员统计与可视化**: 
  - [x] 统计课程报名量、作业完成率、论坛活跃度。
  - [x] 使用ECharts以柱状图、折线图、饼图展示全平台数据。

## 6. 学习交流论坛模块
- [x] **发帖与回复**: 教师和学员在论坛内发布学习问题、心得，并可相互回复。
- [x] **点赞与收藏**: 帖子支持点赞与收藏操作。
- [x] **论坛管理**: 管理员与教师有权删除或屏蔽违规帖子。

## 7. 基础信息管理
- [x] **用户管理**: 管理员对学员、教师进行增删改查。
- [x] **个人中心**: 各类角色查看与自身相关的统计数据（如学员的学习进度、教师的授课数据等）。

## 技术实现要求
- **后端框架**: SpringBoot
- **持久层框架**: MyBatis
- **权限安全**: Spring Security
- **数据库**: MySQL
- **前端框架**: Vue.js + ElementUI
- **图表库**: ECharts
- **架构**: B/S, 前后端分离, RESTful API

## 补充说明
- [x] 所有接口均为真实业务接口，坚决不使用任何测试接口(如 `/test`)。
- [x] 所有前端功能均与后端真实数据联调完毕。
