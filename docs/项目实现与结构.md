# 培训学习交流系统 - 项目实现与结构说明

## 1. 项目概述
本项目是一个基于 B/S 架构的在线培训学习交流系统，旨在为学员、教师和管理员提供一个高效、便捷的在线教育平台。系统分为三个主要角色：
- **学员 (Student)**：可以浏览已发布的课程、报名参加课程、查看课程资源、提交作业、参与论坛交流等。
- **教师 (Teacher)**：可以发布课程（需管理员审核）、上传课程资源、审核学员报名、发布作业并批改、在论坛答疑解惑等。
- **管理员 (Admin)**：负责系统的全局管理，包括用户状态管理（禁用/启用）、课程发布审核、论坛帖子管理等。

## 2. 技术栈
### 2.1 后端技术
- **核心框架**：Spring Boot 2.7.15
- **持久层框架**：MyBatis Plus 3.5.3 (提供便捷的 CRUD 和条件构造器)
- **数据库**：MySQL 8.0 (存储业务数据)
- **安全认证**：Spring Security (实现基于角色的访问控制，使用 BCrypt 加密密码) + JWT (JSON Web Token，用于前后端分离的无状态认证)
- **接口规范**：RESTful API 风格设计

### 2.2 前端技术
- **核心框架**：Vue 3 (Composition API)
- **构建工具**：Vite 5
- **UI 组件库**：Element Plus (提供美观、现代的组件如表格、表单、对话框、标签页等)
- **路由管理**：Vue Router 4
- **网络请求**：Axios (封装了请求拦截器自动携带 Token，响应拦截器统一处理错误和权限过期)

## 3. 核心功能实现
1. **统一认证与授权**：
   - 用户登录时，后端通过 Spring Security 校验账号密码（BCrypt 对比）。
   - 验证成功后生成 JWT Token 返回给前端。前端将 Token 存入 localStorage，并在后续请求的 Header 中通过 `Authorization: Bearer <token>` 携带。
   - 配置 `SecurityConfig` 放行登录、注册、文件上传和静态资源下载接口。

2. **课程管理与审核机制**：
   - 教师发布课程后，状态为“待审核”（`auditStatus=0`）。
   - 管理员在“系统管理”页面进行审核。审核通过后（`auditStatus=1`），学员才能在课程大厅看到并报名。

3. **文件上传（支持图片/附件）**：
   - 通过 `FileController` 接收 `MultipartFile`，生成 UUID 唯一文件名并保存至本地 `uploads/` 目录。
   - 返回完整的可访问 URL（例如 `http://localhost:8081/uploads/xxx.jpg`）。
   - 前端通过 Element Plus 的 `<el-upload>` 组件实现作业照片、课程课件的上传。

4. **论坛交互与撤回机制**：
   - 用户可以发布帖子和回复。
   - 引入了**限时撤回机制**：用户只能撤回发布时间在 5 分钟内的帖子。
   - 管理员拥有最高权限，可随时删除违规帖子。

## 4. 项目结构说明

### 4.1 后端结构 (`online_study_backend/`)
```text
src/main/java/com/online/study/
├── config/           # 配置类包
│   ├── CorsConfig.java       # 全局跨域配置
│   ├── MybatisPlusConfig.java# MyBatis Plus 分页插件配置
│   └── SecurityConfig.java   # Spring Security 及密码编码器配置
├── controller/       # 控制器层 (RESTful API 接口)
│   ├── AuthController.java   # 登录注册接口
│   ├── FileController.java   # 文件上传接口
│   └── ... (其他业务控制器)
├── entity/           # 实体类层 (与数据库表一一对应)
├── mapper/           # 数据访问层 (继承 BaseMapper)
├── service/          # 业务逻辑层接口
│   └── impl/         # 业务逻辑层实现类
└── utils/            # 工具类包
    └── JwtUtils.java         # JWT 生成与解析工具

src/main/resources/
├── application.yml   # SpringBoot 核心配置文件 (端口、数据库连接、文件上传限制等)
└── mapper/           # MyBatis XML 映射文件 (用于编写复杂 SQL)
```

### 4.2 前端结构 (`online_study_frontend/`)
```text
src/
├── assets/           # 静态资源 (图片、全局样式等)
├── components/       # 公共组件
├── router/           # 路由配置
│   └── index.js      # 定义页面路径与组件的映射关系，包含路由守卫
├── utils/            # 工具库
│   └── request.js    # Axios 实例封装 (拦截器配置)
├── views/            # 页面级视图组件
│   ├── Login.vue     # 登录与注册页面
│   ├── Layout.vue    # 侧边栏与顶部导航布局
│   ├── Dashboard.vue # 首页数据概览 (图表等)
│   ├── Courses.vue   # 课程管理 (学员报名、教师发课、资源上传)
│   ├── Homework.vue  # 作业管理 (发布、提交、批改)
│   ├── Forum.vue     # 交流论坛
│   └── Admin.vue     # 系统管理 (超管专属)
├── App.vue           # 根组件
└── main.js           # Vue 实例入口 (引入 Element Plus、Router 等)

vite.config.js        # Vite 构建配置 (包含解决跨域的 proxy 代理配置)
```
